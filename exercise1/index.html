1955 — Present

About Tim Berners-Lee

Tim Berners-Lee is a British computer scientist best known as the inventor of the World Wide Web. He was born in London in 1955.

In 1989, while working at CERN, he proposed a system that allowed information to be shared through linked documents over the Internet.

His work introduced technologies such as HTML, HTTP and URLs, which became the foundation of the modern Web.

01

Important Events

  1. 1955 — Born in London, England
  2. 1989 — Proposed the World Wide Web at CERN
  3. 1990 — Developed the first web browser and server
  4. 1991 — The first website became publicly available
  5. 1994 — Founded the World Wide Web Consortium
