Tim Berners-Lee

Inventor of the World Wide Web

About

Tim Berners-Lee is a British computer scientist born in London in 1955. In 1989, he proposed the World Wide Web while working at CERN. He created technologies such as HTML, HTTP and URLs. His work became the foundation of the modern Web.

Important Events

  1. 1955 — Born in London
  2. 1989 — Proposed the World Wide Web
  3. 1990 — Created the first browser and server
  4. 1991 — First website became public
  5. 1994 — Founded the W3C

Key Contributions

  • World Wide Web
  • HTML
  • HTTP
  • URL system
  • Web standards
